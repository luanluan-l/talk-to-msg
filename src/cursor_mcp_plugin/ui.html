About Cursor Talk To MasterGo Plugin

This plugin allows Cursor AI to communicate with MasterGo, enabling AI-assisted design operations. created by Luan & overfly

Version: 1.0.0

Note: This plugin is modified based on cursor-talk-to-figma-mcp, originally created by @Sonny Lazuardi.

How to Use

  • Make sure the MCP server is running in Cursor
  • Connect to the server using the port number (default: 9509)
  • Once connected, you can interact with MasterGo through Cursor
